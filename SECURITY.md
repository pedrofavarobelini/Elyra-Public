# Política de segurança

Escopo: código, schema e testes deste snapshot técnico concluído. Não há
garantia de suporte contínuo, prazo de resposta ou programa de recompensa.
Ambientes de demonstração devem usar somente dados sintéticos.

## Reportar uma vulnerabilidade

**Não abra vulnerabilidades em issues ou pull requests públicos.** Use o
[formulário privado de reporte do GitHub](https://github.com/pedrofavarobelini/Elyra-Public/security/advisories/new),
acessível também por Security → Advisories → Report a vulnerability.

Descreva componente, impacto, pré-condições e reprodução mínima com dados
sintéticos. Nunca envie senhas, chaves, tokens, cookies, gravações, diários,
transcrições, exportações ou dados de outras pessoas.

Mantenha os detalhes em sigilo enquanto o titular avalia e coordena uma
resposta ou divulgação responsável. Não teste ambientes de terceiros sem
autorização. Caso o formulário esteja temporariamente indisponível, não
substitua o reporte privado por exposição pública; tente novamente depois.

Proteções e limitações estão em [docs/Security.md](docs/Security.md).
A publicação do código não homologa implantação com dados reais.

# Conteúdo editorial

Cada artigo inclui texto próprio e links às fontes originais. Não copie trechos extensos ou imagens de terceiros. A máquina de estados é DRAFT → REVIEW → PUBLISHED → ARCHIVED; apenas PUBLISHED aparece como publicação normal.

Publicação exige revisão humana, identificador funcional `reviewed_by`, data `reviewed_at` e atualização de versão quando o texto muda. Identificadores de IA não são revisores autorizados. O comando `npm run support:content:build` gera os módulos; `npm run build` verifica se correspondem às fontes.

Revise fontes, links, pertinência e caráter não clínico antes de qualquer alteração. Os conteúdos não substituem atendimento profissional.
